# VCU测试开关桩管理工具 (UDPToggle)

专业的VCU测试开关桩管理桌面应用程序，基于UDP通信协议实现对VCU设备的远程控制和监控。

## 🚀 特性

- **专业UDP通信**: 完整的UDP客户端实现，支持多种数据类型和帧格式
- **桌面GUI界面**: 基于tkinter的现代化桌面应用程序
- **设备管理**: 支持多个VCU设备的连接、监控和控制
- **开关桩管理**: 批量操作、状态监控、分组管理
- **实时监控**: 设备状态实时显示，自动心跳检测
- **配置管理**: 灵活的JSON配置文件系统
- **统计功能**: 完整的操作统计和性能监控
- **专业日志**: 多级别日志系统，支持文件和控制台输出

## 🔧 安装使用

### 环境要求
- Python 3.8+
- Windows 10+ (主要支持平台)
- tkinter (通常随Python安装)

### 安装步骤
1. 克隆或下载项目到本地
2. 进入项目目录：`cd UDPToggle`
3. 配置设备：编辑 `config/devices.json`
4. 启动应用程序：`python main.py`

### 快速配置
编辑 `config/devices.json` 文件，配置您的VCU设备：

```json
{
  "devices": {
    "VCU_2": {
      "slot_id": "2",
      "name": "主系VCU",
      "ip": "20.2.1.10",
      "local_ip": "20.2.1.100",
      "port": 18125,
      "enabled": true
    }
  }
}
```

## 🔌 UDP通信协议

### 数据帧格式
```
+----------+----------+----------+----------+----------+
| 目标节点  | 源节点    | 数据类型  | 数据长度  | 数据内容  |
| (1字节)  | (1字节)   | (1字节)  | (1字节)  | (变长)   |
+----------+----------+----------+----------+----------+
```

### 数据类型
- `0x00`: TAG - 开关桩数据
- `0x02`: CONF - 配置数据  
- `0x0E`: LOG - 日志数据
- `0x04`: MAINT - 维护数据

### 命令格式
- **开关桩命令**: `[命令类型][名称长度][开关名称][开关值]`
- **配置命令**: `[命令类型][数据长度][JSON配置]`
- **心跳命令**: `[心跳类型]`

## 📊 界面说明

### 主界面布局
- **左侧面板**: VCU设备管理
  - 设备列表（槽位、名称、IP、状态、最后通信时间）
  - 连接控制按钮（连接、断开、刷新）
  - 设备统计信息

- **右侧面板**: 开关桩管理
  - 开关桩分组选择
  - 开关桩列表（名称、类型、当前状态、目标状态、描述）
  - 批量操作按钮（全选、打开、关闭、应用更改）

- **底部状态栏**: 状态信息、监控控制

### 操作流程
1. **启动应用程序**: 运行 `python main.py`
2. **连接设备**: 点击"连接所有设备"或选择单个设备连接
3. **启动监控**: 点击"启动监控"开始实时监控
4. **操作开关桩**: 选择开关桩，设置状态，点击"应用更改"
5. **查看统计**: 实时查看设备状态和操作统计

## 🛠️ 配置说明

### 设备配置 (config/devices.json)
```json
{
  "devices": {
    "设备ID": {
      "slot_id": "槽位ID",
      "name": "设备名称", 
      "ip": "设备IP地址",
      "local_ip": "本地IP地址",
      "port": 端口号,
      "enabled": true/false,
      "description": "设备描述"
    }
  },
  "switch_groups": {
    "组名": {
      "name": "组显示名称",
      "switches": [
        {
          "name": "开关桩名称",
          "type": "enum/macro",
          "description": "开关桩描述"
        }
      ]
    }
  },
  "default_states": {
    "开关桩名称": "open/closed"
  }
}
```

### 应用配置 (config/default.json)
- **vcu**: VCU通信参数
- **logging**: 日志配置
- **ui**: 界面配置
- **features**: 功能开关

## 🔍 故障排除

### 常见问题
1. **设备连接失败**
   - 检查IP地址和端口配置
   - 确认网络连通性
   - 查看日志文件中的错误信息

2. **开关桩操作无响应**
   - 确认设备已连接
   - 检查开关桩名称是否正确
   - 查看UDP通信日志

3. **界面卡顿**
   - 降低刷新频率
   - 减少同时连接的设备数量
   - 检查系统资源使用情况

### 日志文件
- 应用程序日志: `logs/vcu_controller.log`
- 日志级别: INFO, DEBUG, WARNING, ERROR
- 日志轮转: 自动按大小轮转，保留5个备份文件
