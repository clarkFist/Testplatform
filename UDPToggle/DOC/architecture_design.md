# UDPToggle 系统架构设计文档

## 1. 系统概述

### 1.1 项目简介

UDPToggle 是一个专业的VCU（Vehicle Control Unit，车辆控制单元）测试开关桩管理工具，基于UDP通信协议实现对VCU设备的远程控制和监控。系统提供了直观的图形用户界面，支持多设备同时连接、批量操作、实时监控等功能。

### 1.2 核心功能

- **设备管理**: 多VCU设备的连接、断开、状态监控
- **开关桩控制**: 远程开关桩状态切换、批量操作
- **项目解析**: 自动解析C源代码，提取开关桩定义
- **实时监控**: 设备状态实时更新、历史记录追踪
- **配置管理**: 灵活的配置文件管理和项目加载

### 1.3 技术特点

- 基于Python 3.10+开发，跨平台支持
- 采用Tkinter构建现代化GUI界面
- 多线程异步通信，保证界面响应性
- 模块化设计，易于扩展和维护
- 完整的日志记录和错误处理机制

### 2.2 分层架构说明

#### 2.2.1 表示层 (Presentation Layer)
- **主窗口 (Main Window)**: 基于Tkinter的主用户界面
- **对话框 (Dialog Boxes)**: 各种功能对话框和配置窗口
- **状态栏 (Status Bar)**: 显示系统状态和操作信息

#### 2.2.2 业务逻辑层 (Business Logic Layer)
- **VCU控制器 (VCU Controller)**: 管理VCU设备的连接和控制
- **开关桩管理器 (Switch Manager)**: 管理开关桩状态和批量操作
- **C解析器 (C Parser)**: 解析C源代码，提取开关桩定义

#### 2.2.3 通信层 (Communication Layer)
- **UDP管理器 (UDP Manager)**: 管理UDP连接和客户端
- **UDP客户端 (UDP Client)**: 具体的UDP通信实现
- **协议处理器 (Protocol Handler)**: 处理通信协议和数据格式

#### 2.2.4 数据访问层 (Data Access Layer)
- **配置管理器 (Config Manager)**: 配置文件的读写和管理
- **文件系统 (File System)**: 文件操作和项目加载
- **日志管理器 (Log Manager)**: 系统日志记录和管理

## 4. 数据流设计

### 4.1 设备控制流程

```
用户界面 → VCU控制器 → UDP客户端 → VCU设备
    ↓           ↓           ↓         ↓
状态更新 ← 状态回调 ← 响应处理 ← UDP响应
```

### 4.2 开关桩操作流程

```
1. 用户选择开关桩 → GUI界面
2. 设置目标状态 → Switch Manager
3. 构建控制命令 → VCU Controller  
4. 发送UDP命令 → UDP Client
5. 接收设备响应 → 协议解析
6. 更新开关桩状态 → 状态回调
7. 界面状态刷新 → GUI更新
```

### 4.3 项目解析流程

```
1. 选择项目文件/目录 → 文件对话框
2. 递归扫描C文件 → C Parser
3. 正则匹配提取 → 开关桩识别
4. 自动分组分类 → 配置生成
5. 加载到管理器 → Switch Manager
6. 界面显示更新 → GUI刷新
```

## 5. 并发设计

### 5.1 多线程架构

```
主线程 (GUI线程)
├── GUI事件处理
├── 界面更新
└── 用户交互响应

监控线程 (Monitor Thread)
├── 设备状态检查
├── 心跳发送
└── 超时处理

通信线程组 (Communication Threads)
├── UDP消息接收
├── 协议解析处理
└── 回调事件触发

后台任务线程 (Background Task Thread)
├── 文件解析处理
├── 批量操作执行
└── 报告生成
```

### 5.2 线程同步机制

- **互斥锁 (Mutex)**: 保护共享数据结构的访问
- **回调队列**: 异步事件处理和界面更新
- **线程安全集合**: 使用线程安全的数据结构
- **条件变量**: 线程间协调和等待机制

## 9. 性能设计

### 9.1 性能目标

- **响应时间**: GUI操作响应时间 < 100ms
- **吞吐量**: 支持同时控制 16+ VCU设备
- **并发处理**: 支持 1000+ 开关桩同时管理
- **内存使用**: 常驻内存 < 200MB

### 9.2 性能优化策略

- **异步处理**: 非阻塞的网络通信和文件操作
- **数据缓存**: 智能缓存机制减少重复计算
- **批量操作**: 批量处理减少系统调用开销
- **连接池**: 复用UDP连接减少创建销毁开销
